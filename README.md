# Portfolio — Léo Liénard

Portfolio personnel d'un étudiant en Bac pro CIEL option IT, orienté réseaux et infrastructure.
En ligne : **[leodev.fr](https://leodev.fr)**

## Contenu

- Présentation et parcours (stages, certifications : Cisco NetAcad, Root-Me Pro, ANSSI, PIX)
- Lab réseau interactif façon Packet Tracer (topologie SVG animée)
- Terminal interactif dans le navigateur
- Design sombre et rouge, animations, adapté du mobile au grand écran

## Structure

```
index.html        page unique
css/style.css     styles
js/main.js        interactions, animations, terminal
assets/leo.jpg    photo
robots.txt        consignes pour les moteurs de recherche
sitemap.xml       plan du site
```

## Lancer en local

Aucune dépendance : ouvrir `index.html` dans un navigateur.

## Technologies

HTML, CSS et JavaScript natifs. Polices Space Grotesk et JetBrains Mono (Google Fonts).
